## Analysis

This is simple problem given the method to solve it is provided in the description.

ROT13 is a version of the Caesar Cipher that shifts each letter by 13 positions instead of the traditional 3. So whereas with shift 3, where A is substituted with C, in ROT13, A is substituted with N, which is 13 letters away. Therefore to decode the ciphertext, all that needs to happen is a shift in the opposite direction. It is also worth mentioning that ROT13 is its own inverse, so you can choose to shift forward and get to the same result.

Using CyberChef and the ROT13 recipe, each letter in the encoded text is shifted by 13 to get to the plaintext version.

## Solution

- Identify ROT13 as the encoding method from the challenge description.
- Decode the ciphertext using a ROT13 decoder such as CyberChef.
- The decoded text is the flag.

### Python
```python
import codecs

ciphertext = "cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}"
print(codecs.decode(ciphertext, "rot_13"))
```

## Key Takeaways

- ROT13 is a Caesar cipher that shifts each letter by 13 positions.
- ROT13 is **self-inverse**, meaning applying ROT13 twice returns the original text.
- ROT13 is an encoding/obfuscation technique, **not secure encryption**, because there are only 26 possible shifts and ROT13 has a fixed shift.
- Recognizing the expected flag format (`picoCTF{...}`) can help confirm that the correct decoding method has been used.
